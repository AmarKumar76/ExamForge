# ExamForge Infrastructure & Deployment Architecture

Organizational framework for containerization, cloud deployment, monitoring, and continuous integration.

## Directory Structure
- `docker/`: Dockerfiles for React client, Express API, and FastAPI AI service
- `aws/`: AWS ECS task definitions, S3 bucket policies, and cloud infrastructure templates
- `monitoring/`: Prometheus configuration (`prometheus.yml`) and Grafana dashboard definitions
- `ci-cd/`: GitHub Actions workflows (`.github/workflows/deploy.yml`) for automated lint, test, build, and deployment

*Note: Deployment scripts and templates will be populated during the DevOps Implementation phase.*
